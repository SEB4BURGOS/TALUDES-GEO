# TALUDES GEO

Calculadora de estabilidad de taludes por equilibrio límite, que replica la metodología de GEO5 (superficie circular, búsqueda de grilla).
Hecha para Mecánica de Suelos II (PUCV).

- Métodos: Fellenius, Bishop simplificado, Spencer, Morgenstern-Price
- Varios suelos, nivel freático, sobrecarga, sismo pseudoestático (Kh)
- Ejemplos de la ayudantía (Ej. 1 y Ej. 2) cargables desde la página
- `GUIA.md`: paso a paso desde cero. `BITACORA.txt`: comparación con GEO5.

Herramienta de apoyo; no reemplaza software certificado ni el juicio de un profesional.
